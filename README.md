# Práctica de Teoría de Autómatas

Proyecto con arquitectura limpia para conversión AFND → AFD, minimización, simulación y comparación de autómatas.

## Tecnologías

- Backend: Java 17 + Spring Boot
- Frontend: React + Vite + Tailwind CSS + React Flow

## Estructura

- `backend/`: lógica de negocio, controlador, servicios, algoritmos, DTOs y modelos.
- `frontend/`: interfaz modular con componentes reutilizables, servicios y páginas.

## Instrucciones

- Backend: `cd backend && mvn spring-boot:run`
- Frontend: `cd frontend && npm install && npm run dev`
